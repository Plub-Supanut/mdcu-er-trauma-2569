# ER & Trauma · logo system

## Concept

**Two course columns. One shared pulse.**

- Crimson column = **3000539 Emergency Medicine**
- Brass column = **3000537 Traumatology**
- Ivory pulse line = the shared rotation, handover, and one field guide
- Deep ink tile + brass hairline = the pocket-guide / clinical-seal register already used on the page

The mark is deliberately abstract enough to survive a 16 px browser tab, but still reads as a clinical trace rather than a generic medical cross.
